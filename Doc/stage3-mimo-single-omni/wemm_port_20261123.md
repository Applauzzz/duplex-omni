# WeMM 原生 vLLM 补丁移植

## 范围

当前父仓库分支为 `模型兼容`，保留已有未提交 Qwen 兼容工作。
这次先移植 vLLM 引擎支持，不替换公开 MiMo 服务，也不自动把
应用的 `--backbone` 默认值改成 WeMM。尚未提交、推送或修改共享环境。

官方来源为 `Tencent/WeMM-Video`，提交
`6cefad232b94e3e190d747251f35799b8b142213`，采用
`patch/vllm/0.31.0/overlay`。本地 vllm-src 基线为
`ba860768a965efadcf059089c04862c46e568242`。

十一份新增模块保留官方实现及来源声明，覆盖语言/视觉骨干、
Whisper/QFormer、音频、视频、ZIP 与时间戳处理。共享文件仅移植 WeMM
相关增量，不带入新版 Gemma、草稿模型等无关修改。
许可证与来源见 `vllm-src/NOTICE.wemm` 和 `LICENSE.wemm-lavis`。

## 本地适配

- HF 公共架构 `WeMMVideoForConditionalGeneration` 根据 text_config
  选择 dense 或 MoE 类；当前 checkpoint 是 MoE。
- 配置验证复用已有 Qwen3.5 混合注意力策略，不能只给 Qwen 类加别名：
  音频编码和权重映射都不同。
- 本地处理器使用 `_apply_hf_processor_main`、
  `_get_hf_processor_text` 和四参数 `_maybe_apply_prompt_updates`，
  不直接使用官方 0.31 的同名旧入口。保持本地 dtype/CPU 输出处理。
- `audio_url` 和现有服务使用的 `input_audio` 均通过 WeMM 专属媒体路径。
  MiMo/Qwen 的原有 input_audio/video 解析不变。
- WeMM 的 `video_audio_url` 仅对 WeMM 开放，视频与配对音频共用一个视频项，
  保留训练时占位符排列。未验收真实视频/ZIP 推理。
- 不更改现有 SSE/采样调度，不增加全文缓冲或 talker。

四个字均单 token、编码解码往返相同，因此可以保留现有分类用词，
但不能复用 MiMo/Qwen 的 ID。应用需按 WeMM tokenizer 解析 ID，
再验收 allowed_token_ids/logprob_token_ids 及阈值质量。

`⏸` 编码为 `[158, 237, 116]`，不是单 token。
应用接入时必须明确允许多 token 文本标记或选用新的模型专属标记，
并更新 prompt 的“单 Token”假设；本轮不修改用户的共享 chat prompt。

## GPU 门槛

`probe_wemm_gpu.py` 使用独立回环端口 8094、GPU 4/5、TP2、eager，
只请求文本、真实 WAV 音频和单 token 分类，结束自动停止自建模型进程。
现有 MiMo 8090/UI 8080 保留。

首轮目录：
`workspace/logs/20261123T083258Z_wemm_port_rr01k95d`。
首轮因 cache 构造参数失败，第二轮权重加载通过后因音频 dummy 缺失失败，
第三轮文字推理通过但 WAV 重采样缺 librosa/ffmpeg。
这些问题已分别修正；WAV/FLAC 新增 scipy resample_poly 后备，
其他格式仍需要可用的 TorchCodec/FFmpeg。一项重采样回归通过。

最终目录 `workspace/logs/20261123T090228Z_wemm_port_f3fx8aht`：

- TP2 BF16 全部分片加载、音频 encoder profiling、KV cache 初始化通过。
- 文字请求六个正文 delta，七个传输块，首块 0.478 秒，结束 0.903 秒。
- 三秒录制音频请求七个正文 delta，八个传输块，首块 0.764 秒，
  结束 1.283 秒。回复“成长话题是永恒不变的话题。”
- 一 token 语义判别输出“有”，返回“有/无”两候选 logprobs，
  分别约 -0.007872 和 -5.132873，margin 5.125。
- 测试服务正常退出 0，GPU 4/5 显存归零，原 MiMo/UI 保留。

以上时间从 HTTP 请求开始计算，不是端点延迟或 TTS 首音频时间。
这确认引擎音频路径/流式接口可用，不证明回复语义正确或分类阈值已校准。
本轮未启动应用 WeMM backbone 或外部 TTS。
