## TTS 结果

CustomVoice，vivian，seed42，PCM16 little-endian / mono / 24kHz；
初始 codec chunk 1 frame，后续默认 25 frames。首次包为 80ms 近静音，
第二包通常带 2 秒音频。没有浏览器播放测量，不能把到达时间称为实际听见时间。
有效能量判定：20ms 窗，归一化 RMS >= .002，属于检测代理而非语音识别。

| 样本 | 音频时长 | 冷/首轮首字节 | 热态首字节 | 热态有效能量到达 | 热态 RTF |
|------|----------|---------------|------------|------------------|----------|
| 中文 | 6.88s | 1.820s | .0278s | .1996s | .0876 |
| 英文 | 5.52s | .0275s | .0257s | .1939s | .0882 |
| 数字日期 | 9.12s | .0363s | .0257s | .1980s | .0858 |
| 混合语言 | 9.04s | .0329s | .0262s | .1924s | .0862 |
| 长句 | 13.36s | .0290s | .0266s | .1985s | .0849 |

所有完整样本 HTTP200、多 chunk、有效 PCM、完整 EOF。两轮 PCM SHA 完全相同。
冷态只测了首字节，未记录有效能量到达；不要把热态结果推回冷态。
只有五类固定样本，无 p50/p95、并发或长会话结论。

独立 Whisper GPU 转写不输入参考正文，只指定语言/转写任务：
中文、英文、数字日期、长句在标点/数字归一化后匹配。
混合句 “Qwen TTS” 被转写为 “Quantit S”；MiMo 音频转写也为 “QuantitaS”。
这说明专有名词发音/识别有风险，不能宣称全部内容准确。
下一轮需人工听测或对照语言/拼读/可配置 pronunciation 策略；
原正文与 TTS 渲染文本必须分别记账，不能静默替换用户文本来掩盖失败。

## 取消证据及限制

首音频前客户端关闭 .0233s；有效音频后关闭 .1935s，已收到2.08s PCM。
对应服务 SpeechE2E cancelled 总时长25.21ms/198.01ms。
服务与客户端计时原点不同，不能相减得到精确后台取消 SLA。
两次均有相同内部 ID 的 Orchestrator 与 AsyncOmni abort 日志，
无 abort timeout/failure；之后两次恢复请求均成功。
源码 abort 路径等待各 stage pool abort 及 bindings 清理后返回确认。

但 6s/18s 后 stage0 running=1、stage1 waiting=1 快照未归零，
它们在下一次正常请求后也存在；pipeline frontend gauges为零，
生成 counters在两个快照间稳定，GPU空闲。可能是 idle stats 陈旧，
没有直接查询真实 scheduler/request/connector 状态，**本阶段仍不验收此门槛**。
没有因此更改 inference 源码。

补充 `/pause?mode=wait&clear_cache=false` 和 `/resume` 均404；
当前服务未启用开发路由，原 probe exit0 只是记录结果，不代表通过。
probe 已修正为非200时失败。下一轮可用隔离 loopback dev-mode
或进程内诊断查询实际阶段状态；开发接口不能暴露为生产服务。
仍需取消紧邻尾包、连续立即新请求和 connector 残留验证。

## 失败与解决

| 尝试/问题 | 原因 | 变化与验证 |
|-----------|------|------------|
| 直接导入当前树失败 | 缺 CUDA 扩展 | run-local binary overlay |
| TTS01 missing flashmla interface | 只合并 .so 不够 | 新 run 递归合并缺失生成依赖，TTS03成功 |
| TTS02 startup timeout | 顺序启动超过默认600s | init/stage-init1800s、OMP4，TTS03成功 |
| during cancellation silence assertion | 取消发生在80ms静音首包 | 改有效能量触发，热态 rerun exit0 |
| Whisper generation失败 | 检查点没有语言/任务映射 | 从自带 tokenizer 生成内存config，GPU retry exit0 |
| 未找到 Orchestrator 日志 | 小写搜索漏掉 Aborted | 大小写完整搜索和内部ID匹配确认 |
| stage gauges非零 | 可能陈旧，未证实 | 稳定counter/恢复证据保留，待直接状态查询 |
| wait/resume补测404 | dev路由未启用 | 记录失败，禁止算通过 |
| 混合 Qwen TTS 偏差 | 发音/识别待定位 | 保留原样本及两种转写，不放宽内容门槛 |

诊断时还出现不存在的猜测路径、指标文件写入竞争、ss/py-spy缺失、
受限 /proc 读取；均未安装工具或覆盖历史文件，详见 progress.md。
